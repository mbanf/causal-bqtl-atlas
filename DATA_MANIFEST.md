# Data Manifest — Causal bQTL Atlas

All data derive from Engelhorn et al. (2025), Nature Genetics, s41588-025-02246-7.

## Required Input Data

### data/raw/ (~3.4 GB)

| File | Size | Source | Description |
|------|------|--------|-------------|
| `B73_NAM5.fa` | 2.1 GB | [MaizeGDB](https://download.maizegdb.org/Zm-B73-REFERENCE-NAM-5.0/) | B73 reference genome |
| `B73_NAM5.fa.fai` | 21 KB | Generated with `samtools faidx B73_NAM5.fa` | FASTA index |
| `Zm-B73-REFERENCE-NAM-5.0_Zm00001eb.1.gff3` | 152 MB | [MaizeGDB](https://download.maizegdb.org/Zm-B73-REFERENCE-NAM-5.0/) | Gene annotation |
| `Zm-B73-REFERENCE-NAM-5.0_Zm00001eb.1_entap_results.tsv.gz` | 12 MB | MaizeGDB (EntAP functional annotation) | Protein descriptions, COG |
| `supp_table_MOESM5.xlsx` | 48 MB | [Nature Genetics S6/S13](https://doi.org/10.1038/s41588-025-02246-7) | bQTL table (S6), ASE tables (S13a/b) |
| `engelhorn_peaks/` (50 files) | 923 MB | GEO [GSE294039](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE294039) | Per-hybrid narrowPeak files (WW + drought) |
| `savadel2021_mf_bc7_nam5.bed` | 622 KB | Savadel et al. 2021, PLoS Genet | MOA-seq footprints (NAM5 coords) |

### data/processed/ (~61 MB)

| File | Size | Source | Description |
|------|------|--------|-------------|
| `bqtl_snp_ww.csv` | 8.6 MB | Extracted from MOESM5 Table S6 | 147,942 bQTL positions |
| `engelhorn_ase_ww.csv` | 37 MB | Extracted from MOESM5 Table S13a | Per-hybrid ASE (well-watered) |
| `engelhorn_ase_ww_gene_summary.csv` | 2.1 MB | Summarized from ASE data | Per-gene ASE summary |
| `engelhorn_ww_vs_ds_expression.tsv` | 956 KB | Extracted from MOESM5 | 24,796 genes, WW vs drought |
| `maize_tf_pwm_database.json` | 399 KB | [PlantTFDB 5.0](http://planttfdb.gao-lab.org/) | 259 PWMs, 36 TF families |
| `nam_founder_genotypes_at_bqtl.tsv` | 12 MB | Script 53b (assembly alignment) | NAM founder genotypes at bQTL |

Upload these to a shared OneDrive folder:

```
causal_bqtl_atlas_data/
├── raw/
│   ├── B73_NAM5.fa              (2.1 GB)

│   ├── savadel2021_mf_bc7_nam5.bed
│   └── engelhorn_peaks/          (50 narrowPeak files)

    ├── engelhorn_ase_ww.csv
    ├── engelhorn_ase_ww_gene_summary.csv
    ├── engelhorn_ww_vs_ds_expression.tsv
    ├── maize_tf_pwm_database.json
    └── nam_founder_genotypes_at_bqtl.tsv
```

**Total: ~3.4 GB**

### After downloading

Symlink or copy data into the project:

```bash
cd causal_bqtl_atlas
ln -s /path/to/causal_bqtl_atlas_data/raw data/raw
ln -s /path/to/causal_bqtl_atlas_data/processed data/processed
```

Or if using OneDrive sync on macOS:

```bash
ln -s ~/Library/CloudStorage/OneDrive-*/causal_bqtl_atlas_data/raw data/raw
ln -s ~/Library/CloudStorage/OneDrive-*/causal_bqtl_atlas_data/processed data/processed
```

## Cross-Project Dependencies

Scripts 56 and 57 optionally use `regulatory_chains.csv` from the bqtl_predict project.
If not available, these scripts will skip the regulatory chain analysis gracefully.
